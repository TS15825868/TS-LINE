# 仙加味正式商品命名｜精選系列（2026-10-27）

## 適用全部商品

非仙加味自行製作的販售商品，顧客端名稱採用「仙加味精選｜正式品名」；自行製作商品不加「精選」。來源不明先核對，不可猜測。

已確認的兩項正式顧客顯示名稱：

- 仙加味精選｜二珍寶
- 仙加味精選｜四珍寶

上述兩項為獨立商品，不能合併成一個 SKU 或一個產品名稱，也不能稱為仙加味自行研發、自製、升級版或一對一替代品。正式包裝上的原廠品名、品牌、製造／負責廠商與法定標示仍照實保留。對外標題的「仙加味精選」是販售方選品定位，不是製造商聲明。

## LINE OA 套用邊界

- 新增／啟用商品前須先核對正式產品來源、產品原圖、規格、成分、價格、庫存、交期、下單與客服資料。
- 不得只因命名規則就把目前隱藏、停賣或尚未接入 LINE 銷售資料的商品直接開放下單。
- 既有顧客對話、訂單、價格與試喝規則不得因顯示名稱調整而改寫。
- 產品卡、關鍵字、FAQ、客服文字、訂單顯示名稱須保持一致；舊關鍵字可作查詢別名，不當作對外主標題。
- 內容修改或生成後先待人工審核，未核准不對外自動發送。
