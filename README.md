# 仙加味 LINE OA 正式版

目前正式部署為 **獨立 LINE OA 服務**，入口只使用 `server.js`。

- `package.json` main：`server.js`
- Render prestart：同步正式銷售母本 → LINE 健康權威檢查 → 正式驗收
- Render start：`node -r ./product-sales-master.js server.js`
- LINE OA 不再與 ERP、貼文中心或社群發布服務共用啟動入口。
- 憑證只從部署平台環境變數讀取，不寫入 GitHub 或公開前端。

## 正式資料權威

- 銷售、價格、試喝與出貨：`line-sales-master.json`
- 六項產品圖片：`line-product-photo-authority.json`
- 執行資料：`data.json`，啟動前由正式母本同步
- 六張產品圖的正式公開路徑：官網 `images/products-v3/`
- `products-v3` 目前已直接存放真正產品實拍原圖，不再存放 DM／海報內容。
- `products-v2` 只保留歷史參考，不得成為 LINE 正式產品卡來源。

## 六個正式產品、六個正式規格

1. 龜鹿膏：100g／罐。
2. 龜鹿飲30cc玻璃罐：30cc／罐（小玻璃罐）；小玻璃裸罐、金色蓋、無貼紙、無外盒、無外袋，不得稱瓶或放大成接近100g罐。
3. 龜鹿飲180cc鋁袋：180cc／包（鋁袋）；保持狹長直立實際比例。
4. 龜鹿湯塊：75g／盒｜8塊裝｜每塊約9.375g；目前只有此一正式規格。
5. 龜鹿膠：600g（1斤）／盒｜32塊裝｜每塊約18.75g。
6. 鹿茸粉：75g／罐。

所有產品圖片一律使用真正產品實拍原圖等比例呈現，不重畫、不裁切、不拉寬拉高、不更換包裝文字或規格。

- 30cc：60元／罐；買10送1，共11罐600元。
- 180cc：200元／包；買10送1，共11包2,000元。

- 龜鹿膏、龜鹿湯塊、龜鹿膠、鹿茸粉依現貨狀況安排出貨，不套用龜鹿飲5～7工作天。

## Rich Menu

正式 Rich Menu 使用一張 2500×1686 的原生完整 SVG 母稿轉 JPEG，不使用照片拼貼、黑色補位或 runtime composite。

六個功能區：

1. 看產品
2. 購物車
3. 幫我推薦
4. 搭配組合
5. 怎麼使用
6. 直接下單

Render 啟動後會自動同步 Rich Menu；若 LINE API 暫時失敗，會有限次安全重試，成功後停止，不會無限呼叫 API。

## LINE 回覆與圖片

- 產品 Flex hero 一律 `aspectMode: fit`。
- 30cc、180cc 與其他產品維持各自實際比例，不強制等高或等寬。
- 「產品DM」顯示文字統一改為「實際產品照片」。
- 非產品說明卡才使用 LINE OA 專用 Q 版小老闆情境圖。
- 小老闆依推薦、搭配、使用、FAQ、客服、品牌與歡迎等語意選擇場景。

## 正式環境變數

LINE OA 必要：

- `CHANNEL_ACCESS_TOKEN`
- `CHANNEL_SECRET`

其他 CRM 或外部服務設定只有在正式程式實際使用時才配置；ERP、社群發布與貼文審核憑證不屬於 LINE OA `start` 的必要依賴。

## 正式檢查

```bash
npm test
npm run check:catalog
```

`npm test` 會檢查：

- 六項產品與唯一正式規格
- 30cc玻璃罐命名與實際尺寸規則
- 180cc狹長鋁袋比例
- 龜鹿飲價格、買10送1、試喝與5～7工作天
- 其他四項現貨政策
- products-v3 正式產品圖權威
- Rich Menu 單一原生母稿與六個點擊熱區
- Webhook 快速回200與健康診斷
- LINE-only 正式啟動入口

## 健康檢查

- LINE OA：`/healthz`
- 產品與出貨規格：`/internal/api/v2/fulfillment-policy/healthz`

貼文審核、社群發布與 ERP 的健康檢查由各自獨立正式服務負責，不再寫在 LINE OA 的正式服務說明中。
